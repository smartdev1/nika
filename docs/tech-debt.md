# Registre de la dette technique

Ce document suit la dette technique assumée délibérément durant le développement pour respecter des délais ou des contraintes spécifiques. Chaque entrée doit être justifiée et un plan de remboursement doit être envisagé.

## Format d'entrée

```markdown
### [ID] - Description de la dette technique

**Origine** : Sprint/X, tâche T-XXX
**Description** : Détails de la dette technique prise
**Impact** : Conséquences si non adressée
**Plan de remboursement** : Comment et quand cette dette sera adressée
**Priorité** : Haute/Moyenne/Basse
```
