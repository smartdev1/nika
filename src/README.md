# Source code

TypeScript source code for the game.

- `main.ts` : Entry point
- `game/` : Core game logic (scenes, world, entities)
- `systems/` : Gameplay systems (dialogue, quests, combat, inventory, party)
- `controls/` : Touch controls (virtual joystick, buttons)
- `data/` : Game data (characters, dialogues, quests, worlds)
- `save/` : Save/load functionality
- `ui/` : UI components and styles
- `types/` : Shared TypeScript types
